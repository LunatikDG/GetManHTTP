Настройки GetManHTTP

Параметры применяются к главной форме обработки после нажатия Применить. Значения сохраняются вместе с остальными настройками обработки в хранилище системных настроек пользователя.

Таймаут

Максимальное время ожидания HTTP-соединения и ответа сервера, в секундах.

  • 0 — ограничение не задаётся (поведение по умолчанию платформы).
  • Любое положительное число — таймаут для каждого выполняемого запроса.

Автосохранение

Если флажок включён, пока открыта главная форма, периодически сохраняются:

  • дерево запросов и данные каждого запроса;
  • таймаут и параметры автосохранения.

По умолчанию автосохранение выключено: данные всё равно сохраняются при закрытии формы (и при ручном сохранении настроек из главной формы).

Интервал автосохранения

Период в секундах между автоматическими сохранениями. Доступен только при включённом автосохранении. Минимальное значение — 1 секунда; при попытке применить меньшее значение выводится сообщение об ошибке.

Отмена

Команда Отмена закрывает окно без изменения настроек на главной форме.
