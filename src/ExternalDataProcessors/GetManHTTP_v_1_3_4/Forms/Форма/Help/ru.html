GetManHTTP — HTTP-клиент для 1С:Предприятие

Внешняя обработка для отправки HTTP- и HTTPS-запросов к REST API и веб-сервисам, просмотра ответов и хранения коллекции запросов между сеансами. Подходит для любых конфигураций на платформе 8.3.14 и выше (рекомендуется 8.3.26+).

Области главной формы

  • Запросы (слева) — дерево папок и сохранённых HTTP-запросов.
  • Запрос (справа) — метод, URI, параметры, заголовки, авторизация и тело запроса. Область недоступна, если в дереве выбрана папка.
  • Результат запроса (внизу) — код ответа, время выполнения, тело ответа, заголовки ответа.

Команда Справка на панели формы или клавиша F1 открывает эту страницу.

Список запросов

Элементы списка хранятся в виде дерева:

  • Папка — только для группировки; данные HTTP-запроса не содержит.
  • Запрос — полный набор полей (URI, заголовки, тело и т.д.) для выбранной строки.

При переключении между запросами текущие данные правой панели автоматически записываются в выбранный элемент списка. В папку можно помещать папки и запросы; внутрь запроса вложить другие элементы нельзя — при перетаскивании структура приводится к допустимому виду.

Элементы можно перетаскивать мышью для изменения порядка и родителя. Новый запрос или папка создаётся относительно текущей строки (внутри выбранной папки или рядом с элементом).

Панель над списком

  • Добавить запрос — новый запрос (то же, что команда «Добавить» в контекстном меню).
  • Удалить — удалить выбранную папку или запрос.

Контекстное меню списка

  • Добавить папку
  • Добавить запрос
  • Скопировать — копия папки (со всем содержимым) или запроса
  • Изменить — переименовать наименование в списке
  • Удалить
  • Расширенный поиск — поиск по наименованиям в дереве

Настройка HTTP-запроса

  • HTTP-метод — GET, POST, PUT, PATCH, DELETE.
  • URI — адрес ресурса (поддерживается HTTPS).
  • Параметры — пары «ключ / значение», добавляются к строке запроса.
  • Заголовки — произвольные заголовки HTTP.
  • Авторизация:
    • без авторизации;
    • базовая (логин и пароль);
    • по токену — значение передаётся в заголовок Authorization (префикс токена настраивается, по умолчанию Token).
  • Тело запроса — варианты: отсутствует, JSON, XML, form-data, двоичные данные (файл).

Кнопка Отправить выполняет запрос с учётом таймаута из настроек обработки. JSON и XML в ответе при возможности форматируются для удобного просмотра.

Результат и сохранение ответа

После выполнения отображаются код состояния HTTP, время выполнения, тело и заголовки ответа. Команда Сохранить в области ответа записывает тело в файл; расширение файла может подбираться по заголовку Content-Type (JSON, XML, HTML и др.).

Настройки обработки

Команда Настройки на форме открывает диалог:

  • Таймаут HTTP-соединения в секундах (0 — без ограничения);
  • Автосохранение — периодическая запись списка запросов и параметров при открытой форме (по умолчанию выключено);
  • Интервал автосохранения — не менее 1 секунды.

Подробнее см. справку формы «Настройки» (F1 в окне настроек).

Сохранение между сеансами

Список запросов, таймаут и параметры автосохранения хранятся в хранилище системных настроек пользователя 1С. При закрытии формы выполняется сохранение (с подтверждением при необходимости); при завершении работы платформы сохранение выполняется безопасно, без лишних диалогов.

Старые настройки одного запроса автоматически переносятся в первый элемент нового списка.

Установка

  1. Скачайте файл обработки .epf из релиза проекта.
  2. Откройте в 1С через Файл → Открыть (нужно право на использование внешних обработок и доступ в интернет).
